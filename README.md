# 🏠 Nestly – PG Finder Platform

Nestly is a full-stack MERN application that helps users discover and explore paying guest (PG) accommodations. It provides a clean and responsive interface for browsing PG listings, viewing detailed information, and connecting with property owners.

---
## ✨ Features

- 🔐 Secure user authentication (JWT)
- 🏠 Browse and search PG listings
- 🔍 Filter PGs by preferences
- 📄 Detailed PG information page
- ❤️ Save favorite PGs
- ⭐ Ratings and reviews
- 💬 Chat with PG owners
- ➕ Add new PG listings
- ✏️ Edit and delete PG listings
- 📷 Upload multiple property images
- 📱 Fully responsive design
---

## 🛠️ Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- Axios
- React Router

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/riyaxwasxhere/nestly.git
```

### Install dependencies

Frontend

```bash
cd frontend
npm install
npm run dev
```

Backend

```bash
cd backend
npm install
npm start
```
